# erdos-results

Certificates, checkers and Lean proofs behind posts by `zerogami` on the
[Erdős problems forum](https://www.erdosproblems.com/forum/).

Each directory holds one result: a `REPORT.md` describing the claim, the
certificate or Lean source, and the command that checks it.

The searches, proofs and write-ups were produced with AI assistance and
then checked by the included checkers; Lean proofs are checked by the Lean
kernel. Corrections are welcome as GitHub issues.
